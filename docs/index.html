Features
Everything you need.
Nothing you don't.
Built for privacy-conscious people who want full control over their personal information.
🔐

End-to-End Encryption

All data is encrypted on your device using AES-256-GCM via the Web Crypto API. Your PIN never leaves your device — not even the server sees plaintext.

📂

Six Secure Categories

Organise entries into Passwords, Medical, Insurance, Travel, Financial, and Emergency categories. Each entry is individually encrypted.

📱

Installable PWA

Install directly to your phone's home screen from any browser — no app store required. Works fully offline once installed.

⏱️

Auto-Lock Timer

Configurable inactivity timeout (5 min, 15 min, 30 min, 1 hour, or never) automatically locks the vault when you step away.

🔴

3-Strike Security Wipe

After three consecutive failed PIN attempts, all vault data is permanently wiped and the app resets to a fresh install state.

💾

Encrypted Backup & Restore

Export your encrypted vault as a JSON backup file and re-import it on another device. Your data stays encrypted throughout the transfer.

🌐

Fully Offline

Service worker caches the entire app. Once installed, MobileVault works with zero internet connection — your data never touches the cloud.

🥧

Raspberry Pi Ready

Self-host on a Raspberry Pi with a SQLite backend. One script installs Node.js, the server, and a systemd service that starts on boot.

👁️

Reveal & Hide

Sensitive field values are hidden by default with a toggle to reveal. Prevents shoulder-surfing when viewing entries in public.

Security
Zero-knowledge.
Zero compromise.
Encryption happens entirely in your browser. The server stores only ciphertext — it cannot read your data even if the database is compromised.
  • ✓
    AES-256-GCM encryption Industry-standard authenticated encryption using the native Web Crypto API — no third-party libraries.
  • ✓
    PBKDF2 key derivation Your PIN is never stored. A 256-bit encryption key is derived client-side using PBKDF2 with 100,000 iterations and a random salt.
  • ✓
    Random IV per entry Each vault entry uses a unique initialisation vector, preventing pattern analysis across entries.
  • ✓
    3-strike data wipe Three consecutive failed PIN attempts permanently destroys all vault data — no recovery, no bypass.

Self-Hosting
Run it on your Pi.
Own your data.
One script installs everything: Node.js, the MobileVault server, and a systemd service that starts on boot. No Docker required.
  1. 1
    Clone the repository Clone from GitHub onto your Raspberry Pi over SSH.
  2. 2
    Install Node.js 20 LTS One curl command via NodeSource sets up Node.js on Raspberry Pi OS.
  3. 3
    Build and start the server npm install && npm run build, then node rpi/server.mjs — SQLite database created automatically.
  4. 4
    Enable auto-start with systemd Copy mobilevault.service and run systemctl enable mobilevault — starts on every boot.

# Clone the repo git clone https://github.com/nzicecool/mobilevault.git cd mobilevault # Install Node.js 20 LTS curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash - sudo apt install -y nodejs # Build and start npm install && npm run build node rpi/server.mjs # Enable auto-start on boot sudo cp rpi/mobilevault.service /etc/systemd/system/ sudo systemctl enable mobilevault sudo systemctl start mobilevault # Check status sudo systemctl status mobilevault journalctl -u mobilevault -f # Access from your phone # http://<raspberry-pi-ip>:3000
